# دورة التجارب واختبارات A/B والاستدلال السببي

## المشروع الختامي
**السؤال:** هل إضافة خيار «اشترِ الآن وادفع لاحقًا» في صفحة الدفع يزيد المبيعات؟

المقاييس:
- **المقياس الرئيسي:** معدل التحويل في صفحة الدفع، أي عدد الطلبات المكتملة ÷ عدد المستخدمين الذين وصلوا إلى صفحة الدفع.
- **مقياس الحماية:** صافي الربح لكل مستخدم بعد خصم رسوم مزوّد خدمة التقسيط، ونسبة التعثر في سداد القسط الأول.
